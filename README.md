# TodoList CLI

Desenvolvimento de uma aplicação para o gerencimento de tarefas.

- A solução será desenvolvida em C# e .NET 10, inicialmente executada pelo terminal.

A primeira versão permitirá criar, listar, concluir, editar e excluir tarefas, utilizando um arquivo JSON para persistência. Nas versões seguintes, o projeto evoluirá para PostgreSQL, recursos avançados de organização, testes, logs, API e interface web.

O objetivo é praticar conceitos importantes do ecossistema .NET, como orientação a objetos, persistência de dados, arquitetura de software, testes automatizados e desenvolvimento web com ASP.NET Core.
